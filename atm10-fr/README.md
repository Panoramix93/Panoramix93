# Traduction française ATM10

- `ATM10-Francais.zip` : pack de ressources, traduit les noms d'items et les
  infos au survol des mods. Côté client, ou distribué par le serveur via
  `server-resource-pack`.
- `ATM10-quetes-fr.zip` : traduction des quêtes FTB Quests. Côté serveur,
  dans `config/ftbquests/quests/lang/`.
